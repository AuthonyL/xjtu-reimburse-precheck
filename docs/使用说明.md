# 报销预检使用说明

这是整理报销发票、材料和劳务发放说明的本机工具。它会提示抬头、重复票据、材料和支出分类问题，最终能否报销仍以学校及课题组最新要求为准。

> 本项目不是西安交通大学官方工具。规则整理自课题组经验和财务处公开要求，以财务处最新规定为准；工具只做预检，不保证报销通过。

## 下载安装

从 [GitHub Releases](https://github.com/AuthonyL/xjtu-reimburse-precheck/releases) 下载当前版本，选择与你电脑对应的文件。预发布版本标有 Pre-release，建议先用资料副本试用：

| 电脑                               | 下载文件                                    |
| ---------------------------------- | ------------------------------------------- |
| Apple 芯片 Mac（M1、M2 等 M 系列） | `ReimbursePrecheck-0.1.0-mac-arm64.dmg`     |
| Intel Mac                          | `ReimbursePrecheck-0.1.0-mac-x64.dmg`       |
| Windows 64 位电脑                  | `ReimbursePrecheck-0.1.0-win-x64-setup.exe` |

Mac 左上角苹果菜单 →“关于本机”：看到“芯片 Apple M…”就选 arm64；看到“处理器 Intel…”就选 x64。Windows 版本是 x64 安装包。

Mac 双击 dmg，把“报销预检”拖到“应用程序”。Windows 双击 setup.exe，按安装向导选择安装目录；安装后可从桌面或开始菜单打开。

本版本没有开发者证书，也未做 Apple 公证，第一次打开可能有系统拦截。只对已确认来自本项目 Releases、且校验和一致的文件使用以下方法：

- Mac：在“应用程序”中右键“报销预检”→“打开”。如果仍拦截，到“系统设置 → 隐私与安全性”找到此应用，点“仍要打开”。
- Mac 提示“已损坏”时，打开“终端”，粘贴下面一行并回车，再重新打开应用。若应用没有放在“应用程序”，请改为它的实际路径。

```sh
xattr -cr "/Applications/报销预检.app"
```

- Windows SmartScreen 提示时，点“更多信息 → 仍要运行”。Windows 主程序、安装与卸载向导使用相同的票据对勾图标；安装包没有代码签名。

如果仍打不开，把系统提示和电脑型号发给项目维护者，不要删除原始发票。

## 整理一个报销批次

每批报销建立一个文件夹，同一次准备报销的文件放在一起。名称可以是日期（如 `20260102`），也可以是项目或用途名，不要求八位数字。按业务分一级子文件夹，每个子文件夹就是一组：

```text
发票/
  20260102/
    转接线.pdf
    PCB/
      发票01.pdf
      支付记录.jpg
      记账单.pdf
    AI/
      海外收据.pdf
      付款凭证.png
      订阅Plan.jpg
    某同学公转组/
      发票.pdf
      高值材料审批表.pdf
    外包设计/
      发票.pdf
      设计清单.pdf
```

批次根目录下的散票归为“根目录”组。组名含“暂缓”时，该组仍检查问题，但金额不计入本批合计；含“公转”会提示入库；含“外包 / 委托 / 加工 / 测试”或票据属于委托服务时，会按委托业务提示。AI 组与海外收据建议列为“资料费”。

选择“发票”总目录后，它下面的一级文件夹都按批次检查，包括非日期名称；排除劳务目录（默认“劳务费”，设置可改）、“无法报销费用”、`tmp`、`_预检` 和以 `.` 开头的目录。空目录、只有忽略文件或普通配置 JSON 的目录不显示；有劳务资料的父批次仍保留劳务节点。批次中的子文件夹递归检查。

批次按日期倒序，同日按名称升序：有效八位日期名用名称日期；其他批次用其中最晚的开票日期；没有开票日期时用目录修改日。侧栏和总览顺序一致。名称里有“横向”或“纵向”都不改变 F2 警告，也不选择经费类别。

同一发票的 PDF、XML、OFD 可以放在同一组，按号码合并计一张。不要把同号 PDF 复制到多个组或批次。海外收据没有 PDF、只有截图时，后面需要手填。

## 总览与批量操作

点击侧栏“批次总览”可回到总览。顶栏显示应用名和可点击的工作区路径，点击路径可在文件夹中显示。侧栏依次是页面导航、批次树和底部设置；“打开其他文件夹 / 全部重新检查”位于批次树标题右侧。表格按批次日期倒序展示状态、开票日期范围或批次日期、张数、已知 CNY 合计、错误 / 警告 / 已豁免数、学校报销单是否存在和最近流转时间。点击批次名称进入报销单；点“合计”展开各支出内容金额与未折算、待手填提示。劳务目录和“无法报销费用”入口在表格下方。

勾选行首复选框，或用表头全选，即可操作选中批次。“批量导出汇总”按表格顺序逐批生成 `_预检/汇总.md`，也会生成现有的入库登记清单和高值材料明细；完成后提示数量。“标记为待提交”只处理允许从当前状态迁移到待提交的批次，动作条预先注明跳过数量。中途失败会停止，并提示已完成的批次数；已生成的文件或状态不会回滚。

## 台账

侧栏“台账”有“报销单”和“发票登记簿”两个标签。报销单表列出当前工作区各批次的状态、经办人、项目、经费类型、张数、已知 CNY 合计、创建与最近流转时间及当前已豁免问题数，可按状态筛选，点击批次回到报销单。页头按状态计数，并汇总已报销单的已知人民币金额；劳务与拒票参考目录不计入。

发票登记簿列出发票号、销方、原币金额、币种、开票日期、所属批次、状态和登记时间。关键字可匹配号码、销方或批次。仍保留在本机登记簿中的其他工作区记录标为“其他目录”，其状态以上次扫描为准。

“导出台账 Markdown”生成工作区根目录下的 `_预检/台账.md`，包含两个表的全部记录，不受当前页面筛选影响。完成后显示路径，可点“在文件夹中显示”。导出文件包含经办人与项目信息，共享前请自行检查。

## 收件箱

打开工作区后，侧栏文件夹树上方的“收件箱”集中列出各批次的未识别文件、未命名附件和解析失败文件，徽标显示待处理数量，空箱不显示徽标。页面按批次分组，每项可打开原文件或在文件夹中显示。

核对文件后，点“是支付记录”等建议按钮即可确认类型；最多显示三个建议，没有文件名建议的未命名附件也提供支付记录快捷按钮。其他材料在“其他类型…”中选择，保存后会重新检查并更新材料要求。建议不代表材料内容已经通过核验。

截图是海外收据时，点“是收据，去手填”跳到所属报销单并定位该组，再在“手填与汇率”里补录。点“忽略”只从收件箱移除，文件仍保留；解析失败的诊断也仍保留。文件更改后点“全部重新检查”。原报销单的材料操作继续可用，也可点“到收件箱集中处理 →”切换。

## 发票列表

侧栏“发票列表”显示当前工作区正式批次的发票列表和张数。可按发票号、销方或品名搜索，勾选一个或多个报销状态，并按支出内容、开始日期和结束日期联合筛选。不选状态表示全部；日期范围包含起止日，未填日期的票不会命中日期范围。

默认按开票日期倒序，点日期、金额或销方列头切换升降序。金额列显示原币；页头张数和 CNY 合计随筛选变化，外币不计入合计并注明未折算数量。金额排序按票面数值，不代表跨币种折算比较。无日期的票始终排在日期排序末尾。

同号出现在多个正式批次时显示“重复号”，悬停可看批次数；同批次不同组不增加该次数。点所属批次跳到报销单并定位分组。列表底部“无法报销费用（参考）”单列拒票目录内容，参与同一筛选，张数和金额不计入上方正式合计。窄窗口可在表格内横向滚动。

尽量把附件放在对应发票同一文件夹，文件名带下列关键字；可以在前后加商家、日期或订单号。例如 `PCB-支付记录-0102.jpg`。

| 店铺证明           | 店铺、商店证明                               |

| 用途说明           | 用途                                         |
| 验收合格说明       | 验收                                         |
| 中行牌价截图       | 汇率                                         |
| 订阅说明           | 订阅、Plan、介绍、定价、introduct、price     |
| 高值材料审批       | 高值材料审批表                               |
| 系统下载审批表     | 系统审批表、系统下载审批表                   |
| 情况说明           | 情况说明                                     |
| 资产登记           | 资产建账、资产建帐、固定资产登记             |

## 报销单页

报销单页头默认显示一行“经办人 / 项目 / 经费”摘要，点击行尾“编辑”才显示表单。经费类型可选“横向 / 纵向 / 其他 / 未填”。离开整行表单或点“保存”会保存到该批次的 `_预检/claim.json`，成功后回到摘要并显示“已保存”，重启应用仍会恢复。保存失败保留编辑内容。元数据只作记录，不改变预检判定；清空字段可移除记录。只读参考目录不提供编辑。

摘要下方的“流转记录（N）”默认收起，展开可查看每次状态变化的时间、从哪个状态到哪个状态以及备注；没有记录时显示空提示。汇总 Markdown 的头部会写入已填的经办人、项目、经费类型和当前状态。

## 打开并逐项检查

1. 第一次在首页点“选择文件夹”，也可以拖入文件夹、粘贴完整路径或点最近打开的目录。以后启动会自动打开上次的工作区，并恢复上次选中的批次。目录被移动或删除时，会回到首页提示原路径，重新选择即可。
2. 左侧是文件夹树，右侧是检查结果。选择“发票”总目录后，所有批次按上述批次日期从新到旧排列；右侧先显示批次总览。点批次或总览表格中的批次名称查看结果，点小三角展开分组，点分组会定位到右侧卡片并短暂高亮。单独打开批次时，如果上级可识别为根目录，也会显示上级的树并选中这一批。没有日期、劳务、拒票等标识且没有散票的纯嵌套目录，其根与批次结构可能相似；请核对顶栏工作区路径和侧栏是否是预期层级。
3. 左侧批次旁的 `✗ 数字` 和 `! 数字` 分别是错误和警告数；“已报销”表示找到学校报销单，仍需自己核对提交情况。分组图标表示材料最差状态。底部灰色“无法报销费用”打开拒票参考表，可以查看原票、记录或修改拒票原因；只允许保存原因，不能在这里手填金额、导出清单或标记提交。
4. 左侧“打开其他文件夹”随时切换工作区，也可拖入新文件夹。拖动左右之间的分隔条调整侧栏宽度；顶栏按钮或 `Cmd+B`（Mac）/ `Ctrl+B`（Windows）收起、展开侧栏。宽度和收起状态会保留，下次启动继续使用。窄窗口会限制侧栏的实际宽度，给结果区留空间。
5. 文件夹树支持上下键移动、左右键展开或折叠、回车打开。右侧单独滚动，顶部工具栏始终可用。设置入口在侧栏左下角，设置页在右侧打开，点左侧批次即可回到结果。
6. 打开目录会一次检查全部批次，之后切换直接用已有结果。批次页“更多 ▾ → 重新检查”只重扫当前批次；确认候选、保存手填或导出后也只重扫这一批，相关批次的重复票提示同步更新。外部新增或改动多个批次文件时，点左侧“全部重新检查”。修改规则后会重新检查整个工作区。
7. 结果页先显示紧凑汇总，随后是“待处理问题”，错误、警告、提示、已豁免合为一个列表，按此顺序排列；默认选中错误和警告，条目为单行概述，点开后可看原因和“怎么处理”。点“定位到分组 →”可滚动到对应材料卡片。提示默认折叠。人民币合计不包括暂缓组和缺汇率的外币，不要把它当作全部材料已经齐全的金额。按组核对材料状态：

| 状态     | 要做什么                                                     |
| -------- | ------------------------------------------------------------ |
| ✓ 已找到 | 点文件名打开，看正文和对应关系是否正确；工具没有替你审阅内容 |
| ? 待确认 | 同文件夹有没命名的图片或 PDF，可能就是材料；打开候选文件核对 |
| ✗ 缺失   | 补齐材料，放进对应文件夹，按建议命名后点“重新检查”           |

待确认时，如果某候选确实是付款截图，点它旁边的“是支付记录”；其他材料同理。应用保存这个文件的类型，自动重新检查，匹配后显示“已找到”。不必重命名哈希文件。误标后可请维护者修改 `_预检/manual.json` 对应的附件覆盖，也可以恢复正确命名后删除错误覆盖。

“在文件夹中显示”可定位原文件。问题列表顶部的“错误 N / 警告 N / 提示 N / 已豁免 N”筛选可多选；选择“提示”可查看已找到等说明，选择“已豁免”可查看理由并撤销。`R1/R11` 表示同一项材料同时被两条规则要求，只列一次。

### 折叠与筛选

左侧文件夹树采用手风琴展开：展开一个文件夹时，同级的其他文件夹及其展开的子目录会自动收起；批次、劳务费和无法报销费用都遵循这个规则。点击批次、恢复上次选中的批次或定位分组时，只展开该批次及其祖先。收起文件夹不会改变右侧正在查看的批次。小三角、右方向键和回车均可展开，左方向键可收起。

批次和劳务页的问题默认显示为一行概述。点击整行展开原因、“怎么处理”、相关文件和操作，可同时打开多条。文字过长会省略，鼠标停在问题文字上可查看完整内容；窄窗口优先保留级别、规则编号和展开箭头。顶部的级别 chips 可多选，默认选择错误与警告；按错误、警告、提示、已豁免排序。下方规则计数（如 `F2 ×3`）只统计所选级别，点击只看该规则，再点同一标签取消；同时只筛选一条规则。唯一一对“全部展开 / 全部收起”只操作当前可见的条目。关闭某级别后，只有该级别命中的规则筛选会自动清除。

“放入改好的文件”和“定位到分组 →”在问题详情里。即使条目收起，也可以直接把改好的文件拖到概述行上进行模拟检查。

“分组与材料”的每个分组行收起后显示组名、标记、支出内容、合计和 `✓ 已找到 · ? 待确认 · ✗ 缺失` 的数量。所有分组默认收起，即使有缺失或待确认材料也不自动展开；点击概述行切换，也可在段头全部展开或收起。点侧栏分组或问题详情里的定位按钮会自动展开材料分节和目标组，再滚动并高亮。

报销单页默认只展开“待处理问题”和“分组与材料”；“发票明细”“手填与汇率”“输出文件”“流转记录”默认收起。劳务卡片中问题之外的四个子段也默认收起。标题概述显示票数和合计、待手填项数、输出文件和替换记录数；待手填大于零时带 ! 标记，但仍需点开填写。发票明细首列按当前显示顺序编号 1…N；劳务卡片也按说明列表顺序标序号，版本组仍只计一笔。

问题、分组和段落的展开状态按批次或劳务目录分别保留在本次会话中，切换页面后仍在；重新检查、保存设置或放入文件后，相同问题继续保持展开，已解决的问题消失。退出应用后，这些展开状态重置，不影响上次工作区和批次的记忆。

## 放入改好的文件

批次问题、劳务卡片以及缺失或待确认的材料旁有“放入改好的文件”，批次页的“更多 ▾”菜单提供“检查单个文件”，劳务页保留工具栏入口。点击只打开拖放面板，不会自动打开 Finder 或系统选文件窗口。把文件拖进去即可；需要浏览文件时，主动点“或从文件夹选择…”。问题条目收起时也能直接拖到概述行。拒票页没有这个入口。

1. APP 把当前批次或劳务目录复制到系统临时目录，在副本里替换或补交，仍会核对跨批次重复、拒票原因和已提交历史。
2. 所选问题消失且没有新增错误时，**直接放入原始文件夹，不再弹确认框**。顶部显示“已放入〈文件名〉，问题已解决”，保留 8 秒，也可以手动关闭。通过只表示符合当前配置，不代表财务批准。
3. 新增警告不阻止放入，提示会注明数量；点“查看详情”可核对本次新增错误/警告以及实际文件操作。这里不列“已找到”等 info，也不重复列整个批次其他未解决的问题。
4. 检查没通过时，只显示目标为什么仍未解决，以及新文件带来的错误、警告；只有“关闭”，不会写任何文件。修改后重新拖入即可。
5. 放入提示上的“撤销”撤销本次操作；提示消失后仍可展开“输出文件 → 替换记录”，点“撤销最近一次”。目录、配置或历史在检查后变化时，APP 会停止放入，要求重新检查。

外部文件的落点规则不变：替换保留原名，同格式沿用原文件名，扩展名变化则使用原名主体加新扩展名。同号 PDF/XML/OFD 优先替换同格式；号码变化归档旧票的整组来源。L6 多版本问题归档旧版本，保留本次采用的一份；选择某份说明的 L1 等问题只处理那份。

补交材料一般放入要求所属文件夹，命名为“附件类型-对象.扩展名”：一张票用原票文件名主体，多张票用组名，例如 `用途说明-合成文具.pdf`、`支付记录-PCB.jpg`；重名加 `(2)`。附件识别和确认不代表内容已审核，拖入前请核对材料。

**文件已经在目录里时：**

- 补交材料若已在正式规则允许的查找范围内（发票同文件夹、允许的批次根目录或按类型命名的材料目录），不复制、不改名，只把附件类型覆盖写进 `_预检/manual.json`；记录显示“确认附件”。T1/T2 仍受同目录及原有匹配条件限制。撤销会还原原来的类型覆盖，没有原覆盖则移除该覆盖，文件留在原处。如果在批次内但属于不允许查找的其他组，仍复制到正确位置。
- 替换文件若已在被替换文件同一文件夹，只归档旧文件，新文件原位保留。同号多格式仍只归档应替换的格式；换号则归档旧号码整组来源，始终保留新文件自身。撤销还原旧文件，原位保留的新文件不移动、不删除。
- 劳务会议附件也支持原位确认：`manual.json` 的 `laborAttachments` 按相对路径记录 `settlement`（会议决算表）、`notice`（会议通知）、`attendance`（签到表），只在说明所在文件夹匹配。普通发票材料沿用 `attachments` 字段。

模拟检查和实际放入采用同一份操作计划。日志仍在 `_预检/旧版/log.json`，原件仍在 `_预检/旧版/<时间>/`；撤销也追加日志。外部放入的新文件撤销时会移入另一个旧版目录，再还原原件和原手填索引；原位确认则只还原索引。如果本次写入的文件或旧版后来被外部编辑，APP 会停止自动撤销，避免覆盖。不要手动修改日志或删除旧版目录。

自动判断时，同号发票匹配替换，新号码需要选组；劳务说明按姓名匹配，多版本时需手选目标；其他文件按类型匹配未齐要求，有多个候选或认不出来时在下拉框选择问题。选定后自动检查，通过就直接放入。

替换劳务说明仍保留全国知名专家等人工条件及发放表金额，移除对应旧说明的解析字段手填覆盖；对应发票的旧手填金额/日期也会移除，外币票需重新核对汇率。其他手填项保留。所有写入仅在当前批次或劳务目录内；旁边的批次和拒票原件不修改。

放入、确认附件和撤销都不会新增反馈。只有你主动点击“这条不对”、填写并保存，才会记录到反馈列表。

## AI 订阅、外币和中行汇率

1. 在“手填与汇率”里找到对应组或收据，填实际支付金额、三位币种代码（如 `USD`、`EUR`）、实际支付日期。多张截图应逐张核对，付款凭证或订阅介绍不要重复当成收据补录。
2. 汇率类型默认是“现汇买入价”，以课题组当前要求为准；也可在设置里统一修改。
3. 点“打开中行历史牌价”，在银行页面自行选择支付日和币种，点查询。出现滑块验证码时由你自己完成，APP 不会处理或绕过验证码。
4. 查询出结果后，点需要使用的价格单元格，例如“现汇买入价”这一列。所选格会被红圈标记，APP 截图时会隐藏自己的提示条，只保留银行页面与红圈。
5. 中行按每 **100** 外币报价，窗口会自动换成每 **1** 外币汇率。例如点 `669.87`，保存的汇率是 `6.6987`。日期、币种或价格列不符时会拒绝保存，按提示重新选择。
6. 保存成功后关闭银行窗口，回到结果页核对金额和汇率。自己手填汇率时，“汇率（每1外币兑人民币）”必须填 `6.6987`，不要填 `669.87`。点“保存手填”后重新检查。

银行网页加载失败、验证码失败或版式变化时，可以手填汇率，自己截图并圈出使用的价格，把图片放进对应业务组，文件名带“汇率”。不要跳过日期、币种和价格类型核对。暂时没有汇率可留空，相关外币会单列，人民币折算留空。

同日同币种截图若已被其他组引用，不能用不同价格覆盖它；遇到提示请核对各组支付信息，必要时分别手工保存截图和填写。

## 导出和保存

点“导出到批次文件夹”，完成后可打开文件，或点“打开输出文件夹”。导出在当前批次的 `_预检/` 内，不会改动原始发票；再次导出会覆盖同名清单。

| 文件                 | 用途                                                                        |
| -------------------- | --------------------------------------------------------------------------- |
| `入库登记清单.xlsx`  | 需要入库的发票明细，按销方分表；核对后用于学校入库登记                      |
| `高值材料明细.xlsx`  | 高值材料明细及情况说明草稿；必须按真实用途、寿命修改草稿                    |
| `汇总.md`            | 分组、三种材料状态、问题及分类金额，可用文本编辑器打开                      |
| `manual.json`        | 你保存的金额、支付日、汇率和附件类型；平时由 APP 维护，保留它可在重开时恢复 |
| `汇率-日期-币种.png` | 中行红圈截图，可作为财务材料人工核对后使用                                  |
| `rates.json`         | APP 保存的截图关联索引，供重新检查时找到对应组的汇率附件                    |
| `旧版/时间戳/`       | 自动放入及撤销时保存的原件、新件和索引快照，不参与检查                      |
| `旧版/log.json`      | 放入与撤销记录，输出区可查看                                                |

不要随手删除 `_预检/`，否则手填和确认记录也会丢失。导出的 Excel 和 Markdown 是结果快照；改动发票、手填或规则后应重新检查、重新导出。工具生成的情况说明只是草稿，不是审批结果。

## 报销单状态

批次页头右侧只有“导出到批次文件夹”主按钮和“更多 ▾”菜单。菜单内提供“检查单个文件”“重新检查”“打开输出文件夹”；导出内容和保存位置不变。

批次页的状态徽标显示草稿、待提交、已提交、已退回、已报销、已拒绝或已取消。点“状态：草稿 ▾”（文字随当前状态变化）展开菜单，只列出允许的目标，例如“标记为待提交”：准备好材料后转为待提交，按学校流程提交后再转为已提交，到账后转为已报销。选择退回或拒绝后须在页头内联表单填写备注，再点“保存状态”；待提交和已提交可退回草稿，已退回可转回草稿。已报销、已拒绝和已取消是终态。

状态和备注保存在 `_预检/claim.json`，移动或改名时应携带整个批次。已提交和已报销的发票号进入本机登记簿，检查其他批次时用于查重。扫描到学校报销单只会提示，不自动改变状态；这些操作不向学校系统提交材料。

问题行可点“豁免…”填写理由；已豁免问题默认隐藏，选择“已豁免 N”后显示，且不计入待处理数量，汇总末尾保留规则及理由，也可撤销豁免。

## 本轮财务补充要求

工具不区分当前批次是横向还是纵向经费。命中下面限制时，都先提示你核对：

- **F2 只能走横向**：文具、教具、教学用具、办公用品、打印、复印、印刷、快递服务、收派服务、邮政、邮寄、当天达、客运、出租、网约车、地铁、公交。显示警告“此类费用只能走横向经费，纵向项目请拆出单独报销”。原来文具/办公用品的 R14 错误已替换，不再一概判为不能报销。
- **F6 用途说明**：办公用品、文具、日用杂品、日用品、生活用品、清洁用品、洗涤剂需要说明实际科研用途。文件名带“用途”，放在对应组。
- **F5 委托发票税目**：委托票全部明细均为明确的非服务税目时仍报错误，请联系对方重开；混有服务行和材料行时改为警告，点名材料及不含税/含税金额，材料部分需要入库，或请对方分开开票。混合票级别可在设置的 F5 卡片单独调整。服务税目缺失时先核对解析告警，不会仅因没读出税目就断言开成材料。AI 组不走委托业务规则。
- **委托材料**：委托业务费需要对方盖章的明细清单（R5/R6）；组内非 AI 的人民币发票合计达到 50000 元，需要合同原件和验收合格说明（F5-documents）。清单按名称找到后，你仍须确认盖章及内容是否对应。
- **F1 旧版电子发票**：票面有“发票代码”等旧版字段时，提示确认有发票专用章。数电票不提示；票种会显示在发票明细表中。

加工服务按服务类检查，“金属加工机械”等明确实物税目仍检查入库和高值材料，避免被“加工”两个字误归类。已有明确税目时优先按税目识别委托，没有税目时再用名称或文件名兜底。

这些默认关键字和金额方向都能修改。默认“≥”包含边界值；高值材料按含税单价判断。公转票即使混有服务行，器件入库要求仍保留，不能用服务行遮掉实物要求。

## 行程单与运单明细

设置“规则”新增“课题组惯例”分组，可分别关闭 T1 / T2、修改级别及识别关键字；默认都为 warning。关闭规则前请与经办老师确认。

- **T1 市内交通附行程单**：客运、打车、网约车、约车、地铁类发票需要行程单。把票与对应行程单放在同一文件夹，尽量保留下载时的同名前缀，例如 `【合成出行-20元-1个行程】电子发票.pdf` 和 `【合成出行-20元-1个行程】电子行程单.pdf`。
- APP 先去掉扩展名和电子发票/电子行程单等后缀，按前缀匹配；再按行程单文字中的“合计 XX 元”或文件名金额匹配，金额容差 0.01 元。一份行程单只能配一张票。前缀或同金额有歧义时保留待确认，不任意选一份。
- 无对应行程单为“缺失”；同文件夹仍有未匹配行程单时为“待确认”，请打开核对后整理为正确的前缀。已经配给其他票的行程单不能重复使用。截图不做 OCR，没有可读金额时建议用同名前缀。
- **T2 邮寄附运单明细**：快递、收派服务、同城急送类发票需同文件夹的运单明细或订单详情。文件名可用 `发票运单明细.pdf`、`同城订单详情.pdf`。一份涵盖多张发票的明细可共同匹配，仍需经办人核对实际订单对应关系。

这两类材料也可用“放入改好的文件”补交；发票在更深的子文件夹时，APP 会放到该票实际所在目录。其他材料的原有查找规则不变。

F2 新增关键字：打车、约车、出行、客运服务、交通运输服务、印刷品、同城急送。批次名称含“横向”仍会给出 warning。旧配置未修改的默认关键字会升级，自己定制过的词表保留，可在设置里自行补充。

## 拒票原因

点左侧“无法报销费用”，右侧显示文件、品名、金额和原因：

- 已记录：显示原因和记录日期；点“修改”可以更新。
- “可能：……”：使用不同样式显示当前规则推断出的原因，仅供参考，不代表财务原结论。
- “未记录”：既没有历史记录，也没有可确定的本票规则线索；不要猜测原因。

点“记录原因”，填入财务反馈或经办人已确认的事实，再点“保存原因”。保存后回到批次，重复出现在该拒票集合里的票会显示该原因。只修改固定的 `无法报销费用/_预检/reasons.json`；其他拒票资料保持只读。没有读出发票号的文件不能按号码记录原因，应先核对原件。

推断逐张票进行，只看横向限制、抬头和委托发票税目，不把“少了付款凭证”等缺材料情况当作拒票原因。同一个归档文件夹里另一张服务票不会改变本票的推断。

## 修改和共享规则

点侧栏左下角“设置”，右侧标签可切换规则、材料识别和其他配置：

| 标签         | 可修改内容                                                                                                                                                      |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 规则         | 按 README、财务补充、劳务费、课题组惯例、系统检查分组；来源组默认展开，每条规则默认收起。收起时可直接切换启用，展开后编辑级别、阈值、关键字并查看原文和当前口径 |
| 劳务标准     | 同时核对的咨询费两套标准、其他劳务上限和各类型情况说明模板；直接在表格里编辑，金额保留小数                                                                      |
| 附件识别     | 各类材料文件名关键字、共用材料目录、哪些材料允许未命名候选、忽略的扩展名                                                                                        |
| 分组         | 暂缓、公转、委托、AI 及劳务目录名称；劳务目录按完整名称匹配                                                                                                     |
| 支出内容     | 默认/AI/委托/待定名称，以及税目和品名到支出内容的映射                                                                                                           |
| 通用         | 购买方名称和税号、汇率类型、中行页面地址、情况说明理由库                                                                                                        |
| 高级（JSON） | 编辑同一份完整规则，适合维护者批量修改                                                                                                                          |

关键字输入后按回车加入，点词旁的 × 删除。删除全部关键字表示不再按该列表匹配；是否继续启用整条检查，用规则开关控制。多个规则引用相同配置时，修改其中一处会同步显示在其他卡片。

编号含义：`R + 数字` 对应“发票/README.txt”的原编号；`F + 数字` 对应财务补充编号；`L` 是财务第 7 条的劳务细分；`T` 是课题组惯例；英文编号是系统检查。`F5-documents` 是财务第 5 条的合同与验收细分。`R14` 是只读历史说明“不要写文具办公用品类的”，已由 F2 代替，不再作为独立规则检查。

规则总览可按编号、名称或原文搜索，通过“按来源 / 按类型”切换分组，标题显示条数和编号列表。“全部展开 / 全部收起”作用于当前搜索结果的规则卡片。原文不会随着阈值编辑而改变；判定口径立即显示当前编辑值和比较方向，关键字超过 8 个时显示摘要，停留在口径文字上可查看完整列表。保存前仍采用已保存规则，点“保存设置”后重新检查全部批次。

问题条目展开后也有“规则说明”：含编号含义、原文、当前口径和本条问题的实际级别；合并编号逐条说明。点“在设置中查看 / 修改 →”会清除规则搜索、展开对应来源组与规则并滚动过去。

“附件识别”“分组”“支出内容”的条目默认只显示名称和关键字或映射数量，点开编辑；“劳务标准”先分为收起的“咨询费”“其他劳务费”两段，展开后编辑标准与相应模板。收起表单不会丢弃尚未保存的输入。

“恢复此项默认”先恢复该卡片的开关、级别和相关参数，点“保存设置”后生效。已找到的材料仍显示为提示；级别控制未齐材料及实际问题。同一材料命中多条规则时只列一项，并采用这些已启用规则中最高的问题级别。

- 保存后会立即重新检查当前工作区的全部批次；切回批次查看新结果。
- “导出规则 JSON”可把当前配置发给同组同学；对方用“导入规则 JSON”载入。文件不包含发票和提交历史。
- “恢复全部默认”恢复并保存内置配置，再重新检查工作区。修改前可先导出备份。
- 高级 JSON 保存也通过 core 校验；非法配置会给出错误，不覆盖旧配置。
- 旧配置的 `forbiddenKeywords` 自动合并进 F2；仍保留旧 `designList` 附件类型。原来的默认设计/外包词会随旧配置升级为新默认，已定制的词表继续保留。

设置、最近目录、上次工作区与侧栏状态、已提交历史存在本机用户数据目录，实际位置在设置页底部。没有 `workspace.json` 的旧版本会按“最近打开”的第一项恢复。共享批次时应保留 `_预检/`；共享组内口径时另外导出规则。

## 劳务费检查

把劳务资料放在“发票”根目录的 `劳务费/`，或某个日期批次下的 `劳务费/`。默认按完整目录名识别，可以在设置“分组”中修改。同一劳务目录里，同姓名且合计相同或具体日期重叠的说明会标为 L6“疑似同一笔的多个版本”，汇总只按一笔计：优先采用没有错误或警告的版本，其次采用修改时间最新的版本。两份仍在侧栏显示并互标“另一版本”，卡片注明“已按 1 笔计”。请核对是否确为新旧版本；确实是两笔时应整理各自正确的金额、日期等资料，或在设置中关闭 L6 后自行核对重复。

```text
发票/
  劳务费/
    合成老师发放说明.docx
    发放表.pdf
    会议通知.pdf
    会议决算表.pdf
    参会人员签到表.jpg
  20260102/
    劳务费/
      另一笔情况说明.pdf
```

情况说明支持有文字层的 PDF 和 `.docx`，正文或文件名需包含“情况说明 / 发放说明 / 说明”。发放表和照片只作为附件；没有文字层的 PDF 标成“发放表（无文字层，请手填金额核对）”，不会做 OCR。文件名含“发放表”时优先作为附件。

劳务目录或其子目录混入可解析发票时，顶部会提示“劳务费目录里有 N 张发票，未按发票检查，建议移到单独的批次文件夹”，并列出文件。同号多格式按一张计。这些票不计入劳务笔数或金额，也没有套发票规则；请连同附件移到劳务目录外的批次后再检查。

左侧根目录的“劳务费”在“无法报销费用”上面，展开后每笔以姓名显示；没读出姓名就显示文件名。日期批次内的劳务目录在对应批次下展开。`✓` 表示启用的检查没有错误或警告，`!` 表示有警告，`✗ 数字` 表示有错误。点某笔会定位到右侧卡片；根目录总览也有劳务卡片。

右侧先看汇总，再按序号逐笔处理。问题列表之外的四个子段默认收起，点标题查看或编辑：

1. **问题与处理**在最前面，列表与报销单采用相同的级别筛选，默认显示错误和警告；点“提示 N”查看提示。
2. **抽取字段**旁标“解析”或“手动”。可改姓名、单位、职称、校内外、类型、线上线下、日期、数量及单位、单价及单位、合计和事由。日期每行一个 `YYYY-MM-DD`，例如 `2026-08-01`；月份不会自动补日，没有年份也不会推测成当前年。
3. 勾选“全国知名专家”“六级及以上职员”须有实际依据。论文评审、答辩要选学生层次；监考要确认教师或行政人员，行政人员还要选工作时间或双休日、节假日。
4. **适用标准**显示咨询费两套标准及当前单价在区间内、低于下限还是超过上限。字段改变后先保存重新检查；条件未知或标准表缺行时会提示补充。
5. 在**附件与发放表金额**中打开原表，手填本笔发放表上的金额。它会与情况说明合计对照，不能把所有人的合计填进单笔。点“保存本笔并重新检查”或“保存发放表金额并重新检查”。
6. **生成规范情况说明**按当前字段实时预览。先补齐 `【…】`，确认日期和事由，再“复制文本”或“导出 Word”。导出会保存当前手填，文件在该劳务目录的 `_预检/情况说明-姓名.docx`。同姓名的同名输出会覆盖，请及时另存有用版本。

“恢复解析字段”只清空当前编辑草稿的手动覆盖，保存后生效；不会改变原始 PDF / Word。单纯查看、重新检查不会写原目录。

### 劳务检查规则

所有劳务规则来源是财务补充第 7 条，可在设置“规则”中开关和调整级别。

| id  | 默认问题级别 | 检查内容                                                                                                     |
| --- | ------------ | ------------------------------------------------------------------------------------------------------------ |
| L1  | error        | 每项缺姓名、单位、职称、具体日期、形式、数量、单价或合计分别报错；线上次数或线下天数与日期个数不符给 warning |
| L2  | error        | 数量乘单价与合计、手填发放表金额与合计是否一致，容差 0.01 元                                                 |
| L3  | error        | 超发放上限；仅其他经费超上限为 warning；低于某套下限及校内税后口径给 info                                    |
| L4  | warning      | 讲座、评审、答辩、监考正文写成咨询费，提示改为其他劳务                                                       |
| L5  | warning      | 线下会议需要会议决算表、会议通知、参会人员签到表复印件，并在会议决算中列示                                   |
| L6  | warning      | 同人同额或日期重叠的说明提示另一版本，优先通过版本、其次最新版本，汇总按一笔计                               |

咨询费不选择经费类型，同时比较横向和其他经费：线上按“通讯”每人每次；线下半天按半天，按天计费时两天及以内用“不超过两天（含）”，超过两天用“超过两天”。横向的院士按高级职称；其他经费区分校内外及院士 / 全国知名专家、高级、其他。只超其他经费上限会提示“此金额仅横向经费可发”，两套都超则错误。校内其他经费标准是税后，不会替你计算个人所得税。

数量单位与单价单位分开识别；例如“1天、每半天2000元”会报 L2 单位不一致，L3 仍按半天标准核对单价。应核实后把数量和单价换成同一单位，不能直接用一天乘半天单价。负数不会被转为正数通过检查。

其他劳务按具体类型、人员或学生层次、计费单位查上限；不把“次”自动当成“半天”或“小时”。监考、阅卷的非任课课程等适用条件仍需人工确认。同日多次线上咨询的日期数量检查可能提示不一致，应另补每次具体时间并核对。

在设置“劳务标准”编辑咨询费表、其他劳务上限表，以及每种类型的说明模板；在“规则”L1 / L3 / L4 / L5 卡片改职称、类型、形式和会议附件等识别词。非法上下限、重复标准或不合法枚举不能保存。保存后重查整个工作区。标准按财务手册整理，出处为《西安交通大学评审费等项目开支管理办法》，也可在财务处微信公众号“报销指南”核对；程序不会联网更新标准。

劳务目录 `_预检/manual.json` 的 `labor` 字段保存手动覆盖，键是情况说明相对路径；发放表金额不会从矢量或图片中自动读取。共享劳务目录时保留此文件，标准配置则通过设置的规则 JSON 单独共享。

## 遇到问题怎么反馈

发现误报、提示不够严格、说明不清楚时，展开那条问题，点“这条不对”。选择反馈类型，写一句必填备注，例如“付款记录在同文件夹里，但没有识别到”。批次和劳务问题都可以反馈；同一问题再填会覆盖上次记录，概述行显示“已反馈”。反馈本身不会关闭问题或改变检查结果。

到设置“反馈”可以查看本机标记，也能删除。先打开有问题的工作区，再点“导出反馈包”。列表可显示其他工作区的标记，但本次只导出当前工作区。预览里列出文件及字节数，并展示几条替换前后的脱敏样例。确认后选择保存位置，建议桌面等工作区之外的位置。看到“请把这个文件发给维护者”后，通过与维护者约定的私密渠道发送 ZIP；不要把含原文件或个人信息的包直接贴到公开 Issue。

默认不勾“附带原文件”。包内有问题标记、规则版本、改过的规则、解析诊断和拒票原因。身份证、手机号、银行卡、邮箱和程序抽取到的人名会隐藏，同一人用同一个代号；公司、税号、金额、日期保留，便于维护者修复解析。预览中的“替换前”只在本机显示，不导出。

只有维护者确实需要看原件、你也确认可以提供时，才勾“附带原文件”：这些文件保留原内容，可能含个人信息，不会自动遮挡图片或 PDF 页面。没有文字层的扫描件不做 OCR。导出不会自动发送，也不会修改批次；维护者收到后仍需人工分析规则或政策。

设置顶部的“规则：默认 v…”是默认规则版本。有修改时显示“已自定义 n 项”，导入过规则会显示文件名和日期。新版本默认规则有变化且你有自定义时，会出现“有新的默认规则”。打开后逐项核对旧默认、新默认、你的当前值，选择“采用新默认”或“保留我的”，全部选择后保存，工作区会重新检查。未确认时继续用当前配置。没有自定义则自动采用新默认；旧安装第一次建立版本记录时没有更早快照可比较。

## 隐私与限制

发票在本机扫描、解析和检查，不自动上传，也没有遥测。反馈包由你预览、保存并手动发送。主界面不联网；只有你主动打开的中行窗口会连接银行页面，不会把发票或本地文件上传到银行。

劳务目录走独立的劳务检查，不混入发票张数、金额及查重。

截图类收据不做 OCR，金额、支付日和汇率仍需你核对。附件按文件名、类型目录或你的确认识别，不读取正文来判断是否有效。可读文字 PDF、XML 的解析也可能因版式、字体、加密或损坏失败，需要检查告警。

“未发现错误”不等于学校已经审核通过。品类、入库、支付和审批要求以学校最新要求及经办老师意见为准；更新要求后请同步课题组规则，以课题组和财务处最新要求为准。
